# ChatGPT Voice на Яндекс Станции Миди

Контроллер официального сайта ChatGPT в Chromium на рутованной Станции Миди.
Использует существующий аккаунт, браузерное VPN-расширение и локальные аудиомосты.
Python-часть работает на стандартной библиотеке; API-ключ не нужен.

Версия `0.9.2.dev0` — рефакторинг исходников `v0.8.1-dev` с индикацией состояния,
командами проектов/режимов и нативным преобразованием выходного звука.
В предыдущем живом прогоне проверены ручной вход, запуск Voice через CDP
и ответ через динамик Миди; слышимость подтвердил пользователь. После изменения
выходного тракта плавность реальной речи ещё требует проверки: действует лимит Voice.
На Миди найден и исправлен `SIGTRAP`, вызванный
отсутствующими `/proc` и `/dev/shm` внутри Alpine после перезагрузки.
Непрерывный разговор остаётся экспериментальным: реальная страница может
потребовать ручную проверку Cloudflare через VNC.

## Запуск на станции

Нужны root/SSH, Entware с Python **3.11+**, ALSA `arecord`/`aplay` и установленный
Alpine ARM64 с Chromium. Рабочее развёртывание этой версии —
`/data/midi-chatgpt-voice-refactor`; скрипты также поддерживают прежнее имя каталога.

```sh
cd /data/midi-chatgpt-voice-refactor
eval "$(yse env)"
chmod +x scripts/*.sh scripts/midi-chromium

# Только при первичной установке:
sh scripts/install-alpine-browser.sh
sh scripts/install-midi-audio.sh

# Ручная авторизация и настройка VPN через VNC, без аудио и host Python:
MIDI_LOGIN_NO_AUDIO=1 sh scripts/login-alpine-browser.sh
```

На компьютере откройте SSH-туннель и подключите VNC-клиент к `localhost:5901`:

```sh
ssh -N -p 2222 -L 5901:127.0.0.1:5901 root@STATION_IP
```

После сохранения аккаунта закройте браузер. Запуск голосовой сессии:

```sh
# На Миди с 1 ГБ RAM в живом прогоне потребовалась сжатая подкачка:
sh scripts/midi-zram.sh probe
sh scripts/midi-zram.sh enable

sh scripts/run-visible-voice.sh
```

`midi-zram.sh enable` включает 384 МиБ zram только до перезагрузки, без записи
подкачки на флеш. Уже настроенное устройство он не перезаписывает. Автоматически
скрипты сессии zram не включают. Без подкачки при загрузке Voice наблюдались
нехватка памяти и остановка аудиовывода; результаты приведены в отчёте проверки.

Во втором SSH-терминале, из того же каталога и с окружением Entware:

```sh
python3 -m midivoice open
python3 -m midivoice status
python3 -m midivoice close
```

`open` ждёт подтверждения голосового интерфейса; `close` может отменить
ещё загружающийся `open`. Для полного завершения сессии
нажмите Ctrl+C в первом терминале. Скрипт останавливает запущенные им процессы;
сбой фонового аудио/VNC-сервиса также завершает сессию.
Если сайт требует ручную проверку, состояние `verification` оставляет окно
открытым до `close`. Для доступа к нему запустите сессию с
`MIDI_VOICE_DEBUG_VNC=1`, пройдите проверку в VNC и повторите `open`.

Старые имена скриптов сохранены. `run-headless-voice.sh` выбирает headless-режим,
`login-alpine-browser-native.sh` — ручной вход без аудио.
Общие реализации находятся в `run-voice.sh`, `login-browser.sh` и `scripts/lib/`.
Новый `run-voice.sh` по умолчанию выбирает видимый режим; прямой `midivoice serve`
сохраняет прежнее значение `headless`.

Логотип Миди показывает состояние: янтарный — загрузка, бирюзовый — Voice,
синий — «Чат», лиловый — «Работа», тёмно-фиолетовый — ручная проверка. После закрытия восстанавливаются
штатные LED-триггеры. Кольцо и часы остаются под управлением прошивки.
Во время Voice окно автоматически сворачивается, чтобы сократить отрисовку;
для VNC выполните `python3 -m midivoice ui-show`, затем `ui-hide`.
На существующей Alpine для этого нужен Openbox (новая установка включает его):
`chroot /data/opt/midi-browser/alpine /sbin/apk add --no-cache openbox`.
Подробности и результаты замеров — в [VOICE_TUNING.md](docs/VOICE_TUNING.md).

## Команды

| Команда | Назначение |
| --- | --- |
| `open`, `new`, `close` | Возобновить диалог, начать новый, завершить |
| `project "Название"` | Открыть существующий проект по полному имени |
| `mode-chat`, `mode-work`, `home` | Переключить «Чат / Работа», выйти из проекта на главную |
| `status`, `diagnose` | Текущее состояние, последняя диагностика загрузки |
| `ui-show`, `ui-hide` | Показать окно для VNC, свернуть его при сохранении аудио |
| `snapshot`, `vpn-check` | Снимок текущей вкладки, проверка браузерного сетевого выхода |
| `audio-stats` | Счётчики WebRTC без SDP, адресов и содержимого разговора |
| `doctor`, `browser-probe` | Проверка текущего окружения, пробный запуск браузера |
| `login`, `serve` | Ручной вход на графическом хосте, отдельный контроллер |
| `speech-parse`, `speech` | Разобрать распознанную фразу, отправить распознанную команду |
| `quasar-listen` | Читать локальные события Алисы; `--dispatch` включает управление |
| `mic-check`, `mic-sample`, `mic-serve`, `speaker-test` | Диагностика аудио |

```sh
python3 -m midivoice --help
python3 -m midivoice quasar-listen --dispatch --cancel-stock
```

Скрипт `run-voice.sh` сам запускает и контролирует Quasar-адаптер с ранней отменой
штатного ответа Алисы. Второй адаптер одновременно запускать не нужно.
`MIDI_QUASAR=0` отключает его для ручной диагностики. Прямой `quasar-listen`
без `--dispatch` только показывает метки распознанных команд.

Голосовые команды:

- «Алиса, открой чат джипити» / «Алиса, закрой чат джипити».
- «Алиса, чат джипити, новый чат» — новый разговор в выбранном проекте.
- «Алиса, открой проект Название в чат джипити» — существующий проект по имени.
- «Алиса, чат джипити, работа» / «Алиса, чат джипити, чат».
- «Алиса, чат джипити, главная» — выйти из проекта.

«Новая вкладка» — синоним нового разговора в том же окне. Навигация сохраняет
проект и возобновляет Voice, если он был активен; из состояния ожидания она
открывает интерфейс. Для начала разговора используется команда открытия ChatGPT.
Подробности и результаты проверки — в [VOICE_CONTROL.md](docs/VOICE_CONTROL.md).

## Настройки

Переменные задаются в окружении запуска; `.env` автоматически не загружается.

| Переменная | Значение по умолчанию / смысл |
| --- | --- |
| `MIDI_ALPINE_ROOT` | `/data/opt/midi-browser/alpine` |
| `MIDI_STATE_DIR` | `~/.local/state/midi-chatgpt-voice`; задавайте одинаково для сервера и клиентов |
| `MIDI_CHROMIUM` | `chromium`; скрипты сессии выбирают `scripts/midi-chromium` |
| `MIDI_BROWSER_PROFILE_DIR` | `<state>/browser-profile`; скрипты выбирают профиль внутри Alpine |
| `MIDI_BROWSER_MODE` | `headless` для прямого CLI, `visible` для `run-voice.sh` |
| `MIDI_VOICE_WAIT_SECONDS` | `360`, допустимо `60..900` |
| `MIDI_VOICE_WINDOW` | `800,600`, обе стороны `300..1299`, headless |
| `MIDI_BROWSER_LOW_MEMORY` | `1`; `0` отключает дополнительные headless-оптимизации |
| `MIDI_BROWSER_QUIET_UI` | `1`; сворачивать окно после открытия Voice, `0` оставляет видимым |
| `MIDI_INDICATOR` | `auto`; логотип на Midi, `off` отключает управление индикацией |
| `MIDI_QUASAR` | `1`; запуск адаптера Алисы вместе с сессией, `0` отключает |
| `MIDI_HEADLESS_EXTENSIONS` | `0`; `1` сохраняет расширения в headless; visible сохраняет их всегда |
| `MIDI_CHROMIUM_EXTRA_FLAGS` | Дополнительные аргументы; поддерживаются кавычки |
| `MIDI_SPEAKER_VOLUME` | `100%`, допустимо `1%..100%` |
| `MIDI_VOICE_DEBUG_VNC` | `0`; `1` включает VNC в видимой голосовой сессии |
| `MIDI_VOICE_SCREEN`, `MIDI_VNC_SCREEN` | `800x600x24`; также `640x480x24`, `1024x768x24` |
| `MIDI_LOGIN_NO_AUDIO` | `0`; `1` отключает аудио при ручном входе |

Логи сервисов лежат рядом с Alpine: `controller.log`, `pulse.log`, `mic.log`,
`speaker.log`, `speaker-sox.log`, `quasar.log`, `xvfb.log`, `vnc.log`. Лог управляемого Chromium —
`<MIDI_STATE_DIR>/chromium.log`. Снимки HTML/PNG могут содержать личные сообщения.

```sh
sh scripts/midi-audio-check.sh
sh scripts/browser-performance-check.sh
sh scripts/stop-all.sh --dry-run
sh scripts/stop-all.sh
```

## Разработка

```sh
python -m unittest discover -s tests -v
```

Проверки без оборудования работают и на Windows. Тесты UNIX-сокетов, FIFO,
POSIX-дескрипторов и прав доступа выполняются на Linux. Добавлен CI для
Python 3.11/3.13/3.14 на Linux и Windows; сам workflow локально не запускался.
Для проверок shell на Windows нужен Git Bash в стандартном каталоге либо `sh`
в `PATH`. Runtime на станции требует Linux.

Опциональная установка Python-команды: `python -m pip install -e .`.
На станции достаточно копии исходников; shell-скрипты поставляются в репозитории.
Версия определяется в `midivoice/__init__.py`.

Проверка и отдельное развёртывание через ADB с компьютера:

```sh
adb connect 192.168.1.79:5555
python tools/device.py check
python tools/device.py deploy
python tools/device.py test
```

По умолчанию передача идёт в `/data/midi-chatgpt-voice-refactor`; исходная
установка `/data/midi-chatgpt-voice-poc` сохраняется. `--serial` выбирает устройство.
Helper передаёт команды файлами, учитывает особенности старого adbd и проверяет
SHA256 архива. Для фонового запуска через ADB используйте `nohup setsid`, чтобы
отключение ADB-оболочки не завершало VNC через SIGHUP.
