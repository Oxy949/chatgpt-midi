# Безопасность и персональные данные

- Никогда не добавляйте в Git каталог Chromium `profile` (`/data/opt/midi-browser/alpine/home/chatgpt/profile`), cookies, VPN-конфигурации, историю браузера или резервные копии авторизации.
- Не публикуйте `page.html`, сделанный командой `snapshot`: DOM авторизованной страницы может содержать личные сообщения. PNG-превью тоже может содержать персональные данные.
- Скрипты требуют root для `chroot`/монтирования Alpine, но Chromium запускается от UID 1000. Не запускайте браузер от root и не включайте `--no-sandbox`.
- VNC слушает только `127.0.0.1:5901`; используйте SSH-туннель и не публикуйте порт в локальной сети.
- Пользовательское VPN-расширение может иметь доступ к сетевому трафику и данным страниц. Проверяйте его права и поставщика.
- Проект работает с официальным сайтом ChatGPT и не использует его закрытые API. Пользовательская подписка не гарантирует доступность браузерной автоматизации.
- Перед публичным push проверяйте `git diff --cached --stat` и `git diff --cached` на предмет секретов.
